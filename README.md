# Clean Architecture College API

A college management API built with Node.js, Express, and MySQL. The project demonstrates backend development, HTTP routing, database connectivity, and environment-based configuration.

## Technology stack

- Node.js
- Express
- MySQL
- mysql2
- dotenv

## Prerequisites

- Node.js and npm.
- MySQL Server.
- Git.

## Installation

```bash
git clone https://github.com/MehtaVishesh/clean-architecture-college-api.git
cd clean-architecture-college-api
npm install
```

## Configuration

Create a `.env` file with the database connection variables expected by the application. Configure the MySQL database and required tables before making API requests.

## Run the API

```bash
npm start
```

The start command uses the entry point configured in `package.json`. Consult the source files for the available routes and request formats.

## Key concepts

- REST API development with Express.
- Relational database integration with MySQL.
- Configuration management with environment variables.
- Backend application structure.
